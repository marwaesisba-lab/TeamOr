# TeamOr

TeamOr helps ESI-SBA students find teams for their academic projects in **2CPI, 1CS, and 2CS**.

## Description

This project helps students **create their own teams or find existing teams** in a transparent and organized way.

The goal is to make it easier for students to find suitable teammates based on their skills and project needs.

## Skills & Technologies

To contribute to or understand this project, you should have knowledge of:

* **Node.js**
* **Express.js**
* **REST APIs**
* **SQL and database concepts**
* **API security and performance**
* **Authentication and authorization**

Node.js and Express.js are the main technologies used to build the backend and REST APIs.

In this project, I use **RESTful APIs** to handle communication between the frontend and backend.

### Node.js Packages

The project also uses several Node.js packages and backend security tools, including:

* `http-errors` — HTTP error handling
* `express-rate-limit` — Rate limiting and API protection
* `express-validator` — Input validation and sanitization
* `mysql2` — Connecting Node.js to MySQL/MariaDB

## Main Goals

* Help students create project teams.
* Help students find suitable teams.
* Make team formation more transparent and organized.
* Build secure and well-structured REST APIs.
* Apply database and backend development concepts in a real project.
